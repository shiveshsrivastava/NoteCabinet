## key pts
- agent = anything that perceives env thru sensors + acts on it thru actuators
- agent function (percept seq -> action) vs agent program (actual impl running on some architecture)
- rationality != omniscience
  - rational = pick action maximizing *expected* perf measure given perecpts so far + built-in knowledge
  - perf measure should be about desired env state, not how agent "feels" it's doing
- PEAS framing: performance, environment, actuators, sensors -> nice checklist for specifying any task
- env properties: fully vs partially observable, deterministic vs stochastic episodic vs sequential, static vs dynamic discrete vs continuous, single vs multi-agent
- agent types roughly increasing complexity:
  - simple reflex -> condition-action rules
  - model-based reflex -> keeps internal state
  - goal-based
  - utility-based
  - learning agents wrap all of above (critic, learning element, problem generator)
